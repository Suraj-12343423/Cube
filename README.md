# Cube
# 🧊 3D Rotating Cube

A simple and interactive **3D Cube** built using **HTML, CSS, and JavaScript**.
This project demonstrates 3D transforms, animation, and user interaction in the browser.

## 📄 File Description

### 🔹 index.html

* Defines the cube structure
* Contains 6 faces (front, back, left, right, top, bottom)
* Links CSS and JavaScript

---

### 🔹 cube.css

* Handles styling and layout
* Applies 3D perspective
* Positions faces using `transform`

---

### 🔹 cube.js

* Controls rotation using `requestAnimationFrame`
* Adds interaction:

  * Pause on hover
  * Mouse drag rotation
